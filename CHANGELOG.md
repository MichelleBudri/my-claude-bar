# Changelog

## [1.0.0] - 2026-10-22

- Menu bar item with the Claude 5-hour session usage percentage and a Claude-style starburst icon.
- Menu with session (5h) and weekly (7 days) usage and time until each resets.
- Yellow above 50% and red above 80%.
- Auto-refresh every 2 minutes, manual refresh with ⌘R.
- Launch at login.
